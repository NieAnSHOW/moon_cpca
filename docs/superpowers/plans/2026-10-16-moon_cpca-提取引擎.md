# moon_cpca 提取引擎 Implementation Plan

## Goal
实现 MoonBit 侧中文省市区提取引擎：`extract(text, pos_sensitive?, umap?) -> Location`，行为与上游 Python cpca v0.5.5 逐字段一致（含 quirks），交付 golden 对照套件（由上游 oracle 现生成）、README 示例与 CI。

## Architecture
单向数据链路：兄弟单元产物 `data/adcodes.mbt`（编译期常量，`import { "<module>/data" @adcodes }`）+ 上游 Python cpca（仅**开发期**用作 golden 生成 oracle，不进运行时）→ 引擎匹配模块（窗枚举 + 候选索引 + 归属消歧 + 前缀补全）→ `extract` 公开入口 → golden 比对测试。引擎**不自带第二数据源**；依赖白名单 = `moonbitlang/core/*` + 兄弟数据包。golden 为唯一等价基准，期望值只能由上游实跑产生（禁手改）。

## Tech Stack
- MoonBit 工具链：`moon 0.1.20261012 (748b63c 2026-10-12)`（仓库实测 `moon version`；证据 `probe/PROBE.md` §1）
- 构建目标：native（`preferred_target = "native"`，与兄弟 plan 同一约定；spec §9.2 登记 wasm/js 为 `[LOCAL_DEAD_LINK]`）
- 引擎依赖：仅 `moonbitlang/core`（spec §6 E13 白名单）
- golden 生成器语言：Python 3.12.10（仓库实测 `python --version`）+ 上游 cpca（`chinese_province_city_area_mapper/`，vendored 只读）+ `pyahocorasick`（**仅开发期 oracle 依赖**，已装，实测 `import ahocorasick` OK；不进 MoonBit 运行时依赖清单）
- 上游等价基准：Python cpca v0.5.5（`chinese_province_city_area_mapper/cpca/__init__.py:9`）

> 溯源规则: 每项库名/版本必须溯源 spec 章节号或仓库实际依赖（如 grep 依赖清单文件中依赖项的实际版本），禁止凭记忆填写（如拼错库名、捏造不存在的依赖）。
> 溯源结果: MoonBit 版本 → 仓库实测 `moon version`；Python 版本 → 仓库实测 `python --version`；cpca 版本 → `chinese_province_city_area_mapper/cpca/__init__.py:9`；pyahocorasick → 仓库实测 `python -c "import ahocorasick"`（开发期 oracle 用，非运行时依赖）。引擎发布产物零第三方依赖（spec §6 E13）。

## Global Constraints
- 行为等价优先于结构同构：不必复刻 Aho-Corasick，但可观察行为必须等价（引擎 spec §3 范式）
- 上游 quirks 即契约、**不修正**（同名区取候选首元素、`addr` 吞后续文本、全称/简称同区间去重）（引擎 spec §3）
- pos 口径 = **字符序号 = 码点索引**，按 Char 迭代计数，**禁用 `String::length()`**（UTF-16 码元）（引擎 spec §3 + §4.2）
- `extract` 零网络 / 零文件 IO / 零环境变量读取（引擎 spec §6 E13 ③ + §11 B6）
- golden 期望值只来自上游实跑（A 级证据），禁手改、禁用被测逻辑反推（引擎 spec §4.4）
- 同名候选顺序 = 数据行序，引擎侧**零排序**（引擎 spec §4.3 M-6）
- 依赖白名单：`moon.mod` + 引擎包 `moon.pkg` 的 import 并集 ⊆ {`moonbitlang/core/*`, `"<module>/data"`}（引擎 spec §2 + §6 E13）
