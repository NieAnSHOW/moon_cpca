## 1. 背景（D1）

引用 PRD C1（问题陈述）与 F1 表。核心矛盾一句话：零运行时依赖要求数据进编译期产物，而「直接抄进源码」使 V-01 行数数据的同源性不可证。本 spec 锁定把这对矛盾转化为「一条可重跑生成命令 + 一份可机检比对的产物」所需的全部契约。

---

## 2. 架构（D2）

```
上游 CSV（vendored）
   │  tools/gen_adcodes.py（唯一权威入口，设计 D-03/D-05）
   ▼
区划数据 .mbt 产物（编译期常量，设计 D-01/D-02/D-04/D-06）
   │  被引擎单元 import（兄弟 PRD 10.6 登记）
   ▼
自校报告（stderr + 落盘，PRD NFR 失败可诊断性）
```

模块边界：
- `tools/gen_adcodes.py`：读 CSV → 派生 level → 写 `.mbt` → 自校 → 输出报告。职责单一（生成 + 自校一体，设计 D-05）。
- 数据产物文件：只含记录数组 + 头注释来源标识，无函数、无平台分支（PS2）。
- 产物记录 schema（PRD 10.3 数据字典口径，本 spec 为契约权威）：

| 字段 | 类型 | NULL 性 | 标量类型（MoonBit） | 说明 | 权威源 |
|------|------|---------|---------------------|------|--------|
| `adcode` | String | 非空 | `String` | 12 位定长，逐字等于 CSV `adcode` 列 | 上游 CSV 列（PRD 10.3 摘要行） |
| `name` | String | 非空 | `String` | 逐字等于 CSV `name` 列，长度 1..15（V-04） | 上游 CSV 列 |
| `level` | 枚举 Level | 非空 | `enum Level { Province; City; Area }` | 由 adcode 前 6 位 suffix 派生（设计 D-02） | 本表为权威 |

排列顺序 = CSV 行序（设计 D-04，PRD FR-12）。

## 3. 范式（D3）

- **数据与生成器同源**：产物是生成器输出，不是手工资产；任何对产物的修改必须回到生成器或上游 CSV（生成目录所有权 GO1-GO3，见 §8）。
- **自校内置**：生成命令的成功蕴含自校通过（设计 D-05）；自校失败 = 显式失败，绝不降级为「产出未校验数据」（设计文档 §7 FE1）。
- **派生规则唯一**：level 派生规则只存在于生成器一处；产物只存结果（设计 D-02）。消费方（引擎）如需 level 直接读字段，不重算 suffix。
- **来源标识随包走**：产物头注释而非仅 README（设计 D-06）。
- **命名/组织约定**：MoonBit 惯例 `///|` 分隔顶层项；产物为大数组字面量 + 头注释；枚举 UpperCamel 变体。约定依据：本机实测记录（`F:/Temp/seatprobe/seat.mbt` 用 `pub enum Level { Province; City; Area }` + `///|` 分隔，编译测试通过）与 `derive(Show)` 已 deprecated（`probe/PROBE.md` §7 模板与语言坑段实测记录，实现期用 `derive(Debug)`）。

### 4.2 数据契约（schema 级，DT1-DT3）

- `adcode: String` 非空，长度 12（V-07 机检保证输入侧合规；产物侧由 FR 验收复检）。
- `name: String` 非空，长度 1..15（V-04）。
- `level: Level` 非空枚举，派生规则：`adcode[:6].ends_with("0000") → Province`；`ends_with("00") → City`；否则 `Area`。
- 消费方派生文档（引擎 spec）复制上述标量类型逐字（PRD 10.3 已登记，引擎 spec 回链本表，禁止「同上 / 见生产者」省略）。

### 4.3 生成器契约

- 输入路径（固定，相对仓库根）：`chinese_province_city_area_mapper/cpca/resources/adcodes.csv`。
- 输出路径与 import 字面量（**契约锁定**）：产物写 `data/adcodes.mbt`，同目录附空 `data/moon.pkg`。MoonBit 包 = 目录而非文件，故权威 import 形态为 `"<module>/data"` + 显式别名 `@adcodes`（不可写 `"<module>/data/adcodes"`——该形式实测报 `Cannot find import`）。`<module>` = 实现期 `moon.mod` 声明的模块名（本仓库尚无 `moon.mod`，立项动作属实现期，非契约开放项）。兄弟单元（引擎）`moon.pkg` 写 `import { "<module>/data" @adcodes }`，调用 `@adcodes.adcodes` / `@adcodes.Level`。引擎 spec §10 的 import 字面量开放项据此**已锁定**。
- 来源标识（**契约锁定**，消除与可复现性的冲突）：头注释只含**输入决定**字段——上游文件名 `adcodes.csv`、记录数（V-01）、上游 CSV 内容 sha256；**禁墙钟时间戳**（PRD FR-07 回刷前口径曾含「生成时间戳」，那会使 A2 的 diff = 0 不可达；回刷后口径见 §12.1）。
- 输入异常三类（PRD FR-09）：文件缺失 / 只有表头无数据行 / 缺 `adcode` 或 `name` 列 → 退出码非 0 + stderr 指明缺失项。
- 无网络请求（生成器纯本地文件处理；PRD US-01 验收标准 3）。
- 退出语义：0 = 产出且自校通过；非 0 = 未产出有效产物（含自校失败）。

### 4.4 自校契约

| 自校项 | 判据 | 失败行为 |
|--------|------|----------|
| 记录数 | 产物条数 = CSV 数据行数（V-01） | 非 0 + 报告列出行数差异 |
| 逐字段一致 | 产物每条 adcode/name 与 CSV 对应行相等 | 非 0 + 报告列出前 N 条不一致明细（行号 + 上游值 + 产物值） |
| 等级分档 | 产物 level 统计 = V-02 三档计数 | 非 0 + 列出分档差异 |
| 重名统计 | 产物重名名称数 = V-03 的一致 | 非 0 + 列出名下单条数差异 |
| 行序一致 | 产物第 N 条 = CSV 第 N 行（V-06 锚定首行） | 非 0 + 列出首个偏移行号 |
| 无经纬度字段 | 产物中不含 longitude/latitude 标识（PRD FR-11） | 非 0 + 列出命中位置 |

## 11. 契约可实现性互查（MS1-MS2）

约束条款枚举：
1. C-1 产物零平台分支（PS2 纪律：产物 `.mbt` 不含目标条件编译）
2. C-2 产物零经纬度字段（A11 门禁）
3. C-3 产物行序 = CSV 行序（A12 门禁）
4. C-4 产物字段名与 schema 逐字同形（FL1）
5. C-5 生成器零网络（A3 门禁）
6. C-6 自校失败 = 非 0 退出（§4.4）
7. C-7 来源标识输入决定（头注释只含上游文件名 + 记录数 + CSV sha256，禁墙钟时间戳，§4.3）

两两互查：
- C-1 × C-2..C-7：零平台分支只禁条件编译标记，与字段/行序/网络/退出语义/头注释内容无交集 → 可同时满足。
- C-2 × C-3：行序一致要求逐行搬运 CSV，而 C-2 要求跳过 longitude/latitude 列——实现上「取列的子集 + 保序」即可同时满足，无冲突。
- C-3 × C-4：行序一致不约束字段名；字段名同形不约束顺序 → 可同时满足。
- C-2 × C-4：schema 只定义 adcode/name/level 三字段，天然不含经纬度 → 一致。
- C-5 × C-6：零网络不影响退出语义 → 可同时满足。
- C-7 × A2 可复现性：**曾为冲突对**——PRD FR-07/10.3 原文写「来源标识含生成时间戳」，墙钟时间戳使「重生成 diff = 0」（G-01/A2）永不可达。裁决：C-7 以「输入决定」为权威口径（上游文件名 + 记录数 + CSV 内容 hash），PRD FR-07 与 10.3 `generated_at` 行的「生成时间戳」措辞据此**改判为输入决定字段**（PRD 侧回刷见 §12.1）；A7 门禁同时断言「时间戳 grep 命中 = 0」。
- 结论：**无未裁决冲突对**（C-7 × A2 已裁决），7 条约束可同时满足。
