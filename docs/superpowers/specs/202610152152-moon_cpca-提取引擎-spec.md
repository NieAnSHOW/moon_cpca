## 1. 背景（D1）

上游 `transform` 单条输入的实跑输出（V-05..V-16）是本 spec 全部等价断言的基准。

---

## 2. 架构（D2）

```
输入文本
   │  分词式地名匹配（最长匹配语义，设计 D-07/D-08）
   ▼
匹配区间序列（全称/简称共享候选、区间不重叠、同区间去重）
   │  归属消歧（belong_to，V-19）+ 无上级时取候选首元素（V-04/V-05）
   ▼
命中区划 + adcode
   │  前缀补全（update_res_by_adcode 语义：省/市名按 adcode 前缀反查，直辖市市位 = 市辖区）
   ▼
Location{province, city, area, addr, adcode, province_pos, city_pos, area_pos}
```

数据来源：兄弟单元区划数据产物（PRD 10.6 登记）。本引擎不自带第二数据源。依赖白名单纪律：模块 `moon.mod` 与引擎包 `moon.pkg` 的 import 并集 ⊆ {`moonbitlang/core/*`, 兄弟单元数据包}，白名单外依赖计数 = 0（E13）。本机零第三方依赖工程已实测可 build/test（V-22）。

## 3. 范式（D3）

- **等价优先于同构**：结构不必复刻 Aho-Corasick，可观察行为必须等价（设计 D-07 论证）。
- **quirks 即契约**：同名区取候选首元素（V-05）、`addr` 吞后续文本（V-09）、全称/简称同区间去重（V-15/V-16）都是必须复刻的契约，不是待修缺陷（设计文档 §4 非目标重申）。
- **pos 单一口径**：字符序号（= 码点索引，与上游 Python str 索引同口径，V-11 实测 `index=4`、`len=10`）；实现按 Char 迭代计数，禁用 `String::length()`（UTF-16 码元 = 11，V-12）；调用方只见「序号 + -1」。
- **golden 即基准**：期望值只来自上游实跑（oracle），禁止手写、禁止用被测逻辑反推（设计 D-10/D-11）。
- **命名/组织约定**：MoonBit 惯例 `///|` 分隔；公开符号 `extract`；结构体字段名与 PRD 10.3 数据字典逐字同形（`province`/`city`/`area`/`addr`/`adcode` + `province_pos`/`city_pos`/`area_pos`）。

### 4.4 golden 契约

**文件路径与格式（契约锁定，双产物）**：
- **权威中间件** `testdata/golden.jsonl`：每行一个 JSON 对象，字段 `input`（String）/ `umap`（对象或 null）/ `expected`（8 字段对象：`province`/`city`/`area`/`addr`/`adcode`/`province_pos`/`city_pos`/`area_pos`）/ `upstream_version`（String）。`upstream_version` 逐行冗余写入（不依赖注释形态文件头，故 E9 命令以解析首行 JSON 为准）。
- **MoonBit 侧装载载体** `testdata/golden.mbt`：同一次生成运行产出的**编译期常量**（用例数组 + `Location` 期望字段 + `upstream_version`），供引擎测试以 `import` 消费。**装载方式理由（实测证据）**：本机 `moonbitlang/core` 模块全集（`ls ~/.moon/lib/core`：abort/argparse/array/bigint/bool/buffer/builtin/byte/bytes/char/cmp/coverage/debug/deque/diff/double/encoding/env/error/float/hashmap/hashset/immut/int/int16/int64/internal/json/lazy/lazy_list/lexbuf/list/math/option/prelude/priority_queue/queue/quickcheck/random/range/ref/result/set/sorted_map/sorted_set/strconv/string/test/tuple/uint/uint16/uint64/unit/v128）**不含 fs/io/path 模块**（`grep -rl "read_file\|read_to_string" ~/.moon/lib/core --include=*.mbti` 零命中），`env` 模块仅有 `args/current_dir/get_env_var/get_env_vars/now/rand/set_env_var/unset_env_var`；故**运行时读文件会引入白名单外依赖**（违反 §2/§6 E13），装载必须走编译期常量。JSONL 保留为人类可读 + 可 diff 的权威中间件，`.mbt` 为其派生载体，两者由**同一次运行**产出、禁止单独手改任一（§8 生成目录所有权）。
- **两者一致性**：`python tools/check_golden.py`（或 `gen_golden.py --verify`）断言 `.jsonl` 与 `.mbt` 的用例条数、每条 `input`/`umap`/8 字段期望值、`upstream_version` 逐项相等；不一致 = 非 0 退出。

- C-1 × C-2：单入口返回 §4.2 结构体，无冲突。
- C-2 × C-4：pos 字段是结构体字段之一，同形要求覆盖它；口径不涉字段名，无冲突。
- C-3 × C-8：**曾为冲突对**——若把 C-3 读作「非 core 依赖 = 0」，则兄弟单元数据包（同模块非 core import）被排除，只能内联数据（违 C-8），或 E13 恒 FAIL。裁决：C-3 定义为**白名单口径**（兄弟数据包在白名单内），C-8 不受影响；E13 命令按白名单判别（§6 E13、§9.3）。
- C-3 × C-5：golden 生成器是 Python 工具链（开发期），不进入 MoonBit 依赖清单；白名单只约束发布产物，无冲突。
- C-4 × C-7：quirks 复刻不改变 pos 口径；E6 的非 BMP 用例同时服务两者，无冲突。
- C-5 × C-6：golden 期望由上游实跑产生，天然反映上游候选顺序；与「引擎零排序」一致，无冲突。
- C-6 × C-7：候选顺序是上游行为的一部分，与「不修正 quirks」同向，无冲突。
- C-7 × C-5：复刻 quirks 要求 golden 覆盖 quirk 类用例——已由 §4.4 规模行类别 ⑨-⑬ 承载（V-05 取首元素、V-09 addr 口径、V-13 归属消歧、V-06 umap、V-11 非 BMP pos），E7 逐类断言 ≥ 1 条，无冲突。
- 结论：**无未裁决冲突对**（C-3 × C-8 已在 C-3 定义内裁决为白名单口径），8 条约束可同时满足。
